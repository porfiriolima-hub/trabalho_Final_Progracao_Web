Projeto:
  Cronstruir um site de uma barbearia "Barber Prime", contendo Paginas de HOME, Quem somos, Produtos, Serviços e Login, 
  no login terá uma pagina de acesso ao painel administrativo que tem os agendamentos dos clientes que utilizarem o site.

Descrição:
  Este documento descreve os requisitos funcionais e não funcionais do sistema Barber Prime, um site institucional com funcionalidades de apresentação, catálogo de produtos, catálogo de serviços e módulo de agendamento, além de um painel administrativo para gestão dos agendamentos e produtos.

  O sistema Barber Prime é uma plataforma web desenvolvida para uma barbearia moderna que deseja facilitar o contato com clientes, exibir serviços e produtos, além de permitir agendamentos de forma prática.

  Principais módulos:
  • Home — Apresentação geral da barbearia.
  • Quem Somos — História, missão, visão e valores.
  • Serviços — Lista de serviços com opção de agendar.
  • Produtos — Catálogo de produtos de estética e perfumaria.
  • Login — Acesso ao painel do administrador.
  • Painel Administrativo — Gestão de agendamentos e produtos.
